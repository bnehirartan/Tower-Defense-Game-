##Tower Defense Game in Java##

This project is a 2D Tower Defense game implemented in Java, inspired by the classic real-time strategy genre. 
The main goal is to prevent waves of enemies from reaching the end of a predetermined path by strategically placing towers with different abilities and strengths.

*Getting Started:*
1. Compile and run the project using any Java IDE or command line.
2. Start in Editor Mode to build your map.
3. Save the map and switch to Game Mode to begin defending against enemy waves.
